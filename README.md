# データサイエンス

Course website for the Data Science course at Chiba University Graduate School 
of Global and Transdisciplinary Studies.

千葉大学 総合国際学位プログラムの「データサイエンス」授業のウェブサイト

## About

This website contains lecture slides and materials for a data science course 
taught primarily using the R programming language.

## Publishing

The website is built using [Quarto](https://quarto.org/). To publish updates to 
the site, run:

```bash
quarto publish
```

This will render the Quarto documents and publish them to GitHub Pages.
